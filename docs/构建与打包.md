# 构建与打包

## 0. 前置

| 依赖 | 版本 | 说明 |
|---|---|---|
| Xcode Command Line Tools | Swift 5.9+ | `swift-tools-version: 5.9` |
| Dart SDK | 3.10.x 或更高 | 只用于编译 `MyNASCore`，运行时不需要；本轮验证使用 **3.13.5**（stable，macos_arm64） |
| macOS | 13.0+ | 部署目标，且**仅 arm64** |

> Dart SDK 不常驻仓库。`tools/install-mynas-core.sh` 按
> `DART_SDK` 环境变量 → PATH 里的 `dart` → 常见安装位 依次找，
> 找不到才需要显式设 `DART_SDK=<SDK 根目录>`（含 `bin/dart` 与 `bin/snapshots`）。
> 注意是 `DART_SDK`，没有 `_HOME` 后缀。

## 1. Swift 侧


## 2. Dart 搜索核心

```bash
bash scripts/build.sh core         # 底层：tools/install-mynas-core.sh
```

产物落在 `Resources/MyNAS/bin/mynas-core`（Dart AOT 可执行）。
**注意**：AOT 产物不可复现，同源码两次编译的二进制也不同。
如果要复用既有产物，务必先与已发布包里的那份逐字节比对。

核心与客户端之间有**协议版本闸门**：

```
MyNASCore/lib/protocol.dart            const int coreRevision
Sources/FlashFindCore/MyNASProcessBridge.swift   static let expectedCoreRevision
```

两边必须一致，否则启动即报错退出，不会带着版本错位跑下去。

## 3. 打包

```bash
bash scripts/build.sh package --release \
    --icon Resources/Brand/ShanXun.icns \
    --scratch <项目内的编译暂存目录> \
    --temporary-alias <指向该目录的短软链> \
    --output <项目内尚不存在的新目录>
```

> `--scratch` / `--temporary-alias` / `--output` **必须都在项目内**，
> 脚本逐个 `relative_to(project)` 校验，写 `/tmp/...` 会被拒。
> 理由：`build-record.json` 记的是相对项目根的路径 + SHA-256，出了项目就无从复现。
> `temporary-alias` 还得是自己先建好的软链，指向 scratch 那个目录
> （源码路径太长，Swift 编译产物会被路径长度绊住，所以绕一道短软链）。

### 两条铁律

**① 改了源码必须重编；只改包装绝不重编。**

只调整图标、DMG 布局、说明文本这类"包装"时，用：

```bash
bash scripts/build.sh package --app-from-zip <已发布的 zip> --output <项目内新目录>
```

（`--app-from-zip` 走的是「不重编」路径，因此不需要 `--scratch` / `--temporary-alias`，
也不能带 `--icon`——复用的 app 保留它自己那个图标。）

为什么这么严格：Swift 产物不字节可复现。同一个版本号下出现两个不同的二进制，
比不升级更糟 —— 用户无法判断自己手上的是哪一份。

**② 必须是 `--release`。**

### DMG 布局

Finder 在自动化会话里不会把布局写回 DMG（只会落一个 6148 字节的空壳）。
布局改用预置资源 `Resources/dmg-ds-store`，生成与读回走 `tools/dmg_layout.py`。

> 读只读卷必须用 `open(path, 'r')`，默认 `r+` 会报 `Errno 30`。

### 签名

默认 ad-hoc 签名。要做 Developer ID 签名与公证，需要 Apple 开发者账号，
本脚本不覆盖该流程。

### 交付前

**必须真挂载复核一次**。`hdiutil verify` 查不出"里面少了什么"。

```bash
hdiutil attach 闪寻-1.0.1-arm64.dmg
diskutil info -plist /Volumes/<卷名>   # 卷名以此为准，不要用挂载点名字
ls -la /Volumes/<卷名>
```

## 4. 版本号唯一装配点

`Info.plist` 是版本号的**唯一**来源。界面显示一律走 Core 的 `AppVersion`，
**任何一处都不许自己读 `CFBundleShortVersionString`**（有测试锁）。
