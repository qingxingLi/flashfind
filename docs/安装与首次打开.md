## 安装

1. 双击 DMG，挂载后卷里三样东西：`闪寻.app`、`Applications`（快捷方式）、`安装前说明.txt`。
2. 把 `闪寻.app` 拖到右边的 `Applications`（或本机「应用程序」文件夹）。
3. 推出卷，从「应用程序」里打开闪寻。

## 从旧版本升级（覆盖安装）

直接覆盖即可，设置、已保存的 NAS 密码、AI 授权范围都保留。但有**两件事必须手工做一次**，
原因同一个：本包是 ad-hoc 签名，系统按 **cdhash** 认应用身份，换版本等于换了身份，
旧版本拿到的授权对新版本不认。

**① 钥匙串授权框（1 次）**

首次打开会出现**一个**授权框 —— 不是每台 NAS 一个。1.1.5 起所有设备的密码合并成**一条**
记录，所以你有几台 NAS 都只弹这一次。输入 Mac 登录密码，点 **「始终允许」**。

> 点「允许」只对本次运行有效，下次启动还会再问；只有「始终允许」才是永久的。

**② 完全磁盘访问（开关显示为开，也要重拨一次）**

升级后系统设置里那个开关**可能仍停在打开位置，但授权其实已经失效**，
表现为闪寻设置页写着「未授权」、桌面和文稿里的新文件搜不到。
修法：

1. 系统设置 → 隐私与安全性 → 完全磁盘访问权限；
2. 把「闪寻」的开关**关掉**，停一秒，**再打开**（关不动就点「−」移除，再用「+」重新添加）；
3. **完全退出闪寻（⌘Q）再启动** —— 系统按进程缓存权限判断，不重启不会生效。

这两步只在**换版本**时出现；同一版本内重启、覆盖安装都不需要。

## 首次打开被拦 —— 这是预期的，不是包坏了

闪寻目前是 **ad-hoc 签名、未做 Developer ID 签名与公证**（`TeamIdentifier=not set`），
所以 macOS 第一次打开会弹：

> 无法打开"闪寻"，因为它来自身份不明的开发者。

实测：`spctl -a -t exec` → `rejected`；镜像本身 `hdiutil verify` 是 VALID。
**包没坏，是系统不认识签名身份。** 三选一放行：

**办法 A（推荐，点两下）**

1. 照常双击 app，让弹窗出现一次。
2. 系统设置 → 隐私与安全性 → 滚到底部「安全性」区 →
   会看到「已阻止使用"闪寻"，因为来自身份不明的开发者」→ 点 **仍要打开** → 输入密码确认。
3. 之后就能正常打开了，只需做一次。

**办法 B（右键打开）**

Control + 点 `闪寻.app` → **打开** → 在弹窗里点「打开」。同样只需一次。

**办法 C（终端）**

```sh
xattr -dr com.apple.quarantine /Applications/闪寻.app
```

这条命令只是摘掉"从网上下载来的"标记，不改 app 本身。

> 如果 DMG 双击后完全没反应，先把 quarantine 标记摘掉再开：
> `xattr -dr com.apple.quarantine ~/Downloads/FlashFind-1.1.30-arm64.dmg`

## 为什么会有这一步

签名与公证要 Apple 开发者账号（¥688/年）+ Developer ID 证书，项目**至今未做**。
在此之前所有安装包都是这个状态。做了之后双击即可直接打开，不再有这一步。

## 接入 AI 客户端（可选，默认关闭）

装好之后如果想让 AI 客户端（Claude、Cursor、WorkBuddy 等）能问「你那边有没有这个文件」：

1. 菜单栏图标 → 设置（`⌘,`）→ **AI**；
2. 打开总开关，勾选允许它搜的来源，点「保存」；
3. 点「复制接入提示词」，粘给你的 AI 客户端对话框，按它的提示完成配置即可。

助手 `flashfind-mcp` 就在 App 包内（`Contents/Helpers/`），不需要另外下载。
它走的是本机 socket，不出网；交出去的只有文件名与元数据，不含文件内容、不含绝对路径。
不想用了随时关掉总开关，或在同一页「清空 AI 历史」。
